✅ todoaw

Demo Interaktif

Ini demo statis dari aplikasi todoaw (Flutter). Semua screen, warna, dan fitur inti ditiru dari app asli — berjalan penuh di browser tanpa backend.

  • ✔ Tambah, centang, dan hapus tugas
  • ✔ Kalender + statistik ter-update otomatis
  • ✔ Mode gelap & warna aksen
  • ✔ Data tersimpan di browser (localStorage)
Tips: coba centang tugas di Beranda, lalu lihat Dashboard berubah.

Aplikasi asli: flutter run — repo main.
